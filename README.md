# 신페리오 계산기

골프 월례회 신페리오 점수를 폰으로 바로 계산하는 웹페이지. 무료, 가입 없음, 서버 없음.

주소: https://antcraft159.github.io/sinperio/

## 쓰는 순서

1. **코스·숨김 홀:** 코스 파를 맞추고 숨김 홀 12개를 고른다 (자동으로 뽑기 가능)
2. **타수 입력:** 선수마다 18홀 타수. 한 자리 숫자를 넣으면 다음 칸으로 넘어간다
3. **결과:** 순위표와 메달리스트. "결과 복사" 로 카톡 단톡방에 붙여넣기

입력한 내용은 그 폰의 브라우저(localStorage)에만 저장된다. 새로고침해도 남는다.

## 계산 방식

- 숨김 홀: 전반 6 + 후반 6, 파 합이 코스 파의 2/3 (파 72 코스면 48, 파 71 이면 가까운 정수 47)
- 핸디캡 = (숨김 12홀 타수 합 × 1.5 − 코스 파) × 0.8
- 네트 = 18홀 총타수 − 핸디캡, 낮은 순으로 순위
- 메달리스트 = 핸디 없이 총타수가 가장 적은 사람

클럽마다 다른 규칙은 "우리 클럽 세부 규칙" 에서 고른다.

| 규칙 | 기본값 |
|---|---|
| 숨김 홀 12개의 파 합 | 코스 파의 2/3 |
| 숨김 홀 타수 더블파 상한 | 끔 |
| 핸디캡 상한 | 없음 |
| 핸디캡 표시 | 소수 첫째 자리 |
| 네트가 같을 때 | 핸디캡 낮은 사람이 위 |
